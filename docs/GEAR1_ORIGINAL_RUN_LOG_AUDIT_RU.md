## 4. Важное наблюдение по GSRM и геометрии

В этапе 2 программа выполняла распространение номеров тектонических зон на соседние активные ячейки. После 109 итераций остались 101 orphan cell; исходный код вывел сообщение:

`Now giving up and zeroing strain rates in 101 orphan cells.`

Максимальная обнуленная скорость деформации — 9,13 × 10⁻¹⁷/с, или 2,9 nanostrain/year. Это штатное завершение оригинального алгоритма, но научное ограничение, которое нужно сохранить при оценке покрытия и неопределенности. Мы не переопределяем это поведение при аудите и не считаем отсутствие значения измеренным нулем в новых физических модулях.

Калибровочный GCMT каталог: 6 476 событий за 1977-01-01 — 2013-12-29, длительность 37 лет. Лог содержит распределение событий по четырем зонам границ плит и внутриплитной области, а также scaling factors для зон.

## 5. XML — отдельный следующий контроль

Из журнала видно, что программа начала `Writing .xml file...`, завершила STEP #5 и напечатала `Job completed.`. Это сильное подтверждение завершенного выполнения, но сам выходной XML в эту сессию не загружен. Публичная ссылка на папку Яндекс Диска из сообщения пользователя не открылась через доступные инструменты этой среды, поэтому утверждать, что файл скачан, нельзя.

Чтобы закрыть этот этап, нужен сам `GEAR1.global.forecast.xml` — вложением в чат либо отдельной публичной ссылкой непосредственно на файл. После получения проверю:
1. XML well-formedness и CSEP-структуру;
2. имя модели, даты, пространство, пороги и число magnitude bins;
3. количество forecast data points и отсутствие отрицательных/NaN rates;
4. интеграл XML против 116,2 событий/год выше M5,95;
5. SHA-256 результата и связь с этим логом.

Машиночитаемые данные полного журнала: `research/results/gear1_original_run_2014-2015.json`.
