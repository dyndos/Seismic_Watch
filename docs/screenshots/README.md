# Скриншоты для README

Положите сюда PNG с такими именами (они подключены в корневой `README.md`):

| Файл | Что показывает |
|---|---|
| `01-dashboard.png` | Главная: мониторинг, живой фид USGS, кейсы, формы сценария и новости |
| `02-analysis-header.png` | Шапка карточки события: магнитуда, тип разлома, время |
| `03-analysis-map.png` | Карта: эпицентр, границы плит, стрелка движения плиты, цепочка |
| `04-analysis-forecast.png` | Межрегиональный прогноз и вероятности по горизонтам |
| `05-analysis-validation.png` | Hindcast-валидация «прогноз vs факт» |
| `06-exposure.png` | Риск-профиль города (Стамбул) |

## Как снять автоматически

```bash
npm run build && npm start          # приложение на :3000
npm i -D puppeteer                  # один раз
node scripts/screenshot.mjs         # снимки появятся в этой папке
```

Можно и вручную: открыть страницы в браузере и сохранить скриншоты
(рекомендуемая ширина 1440px, тёмная тема — по умолчанию).
