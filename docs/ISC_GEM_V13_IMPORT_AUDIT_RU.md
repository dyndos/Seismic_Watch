**Дата обработки:** 2026-11-09  
**Источник:** International Seismological Centre, ISC-GEM Global Instrumental Earthquake Catalogue, Version 13.0, released 2026-10-21.  
**Официальные страницы:** [overview](https://www.isc.ac.uk/iscgem/overview.php), [download & legal](https://www.isc.ac.uk/iscgem/download.php), [update log](https://www.isc.ac.uk/iscgem/update_log/).

## 1. Проверка входного архива

В ZIP обнаружены три ожидаемых файла: основной CSV, отдельный supplementary CSV и KMZ-карта. Встроенный заголовок распознан в обоих CSV. Все строки обработаны без пропусков и ошибок.

Основной файл содержит около 77 тыс. событий, что соответствует официальному описанию v13.0. У ISC отдельно указаны 2 762 пересмотренных события за 1940–1963 годы, 1 070 впервые добавленных событий в эти годы и 1 755 событий за 2022 год. Список Supplementary не является частью основного количественного каталога: туда попадают события с высокой неопределенностью положения и/или магнитуды.

## 3. Supplementary не смешивается с main

В supplementary 9 887 записей. У 4 186 строк указано значение Mw, у 5 701 оно отсутствует. Коды качества Mw: D — 9 639; C — 167; B — 81.

В импортёре это сохраняется отдельно:
- `reported_magnitude` — исходное значение из supplementary;
- `mw` — null;
- `mw_eligible` — false.

Создается отдельный `supplementary_catalogue_normalized.csv`; эти события не попадают в оценку основной частотности. Это не означает, что их нужно навсегда игнорировать: для отдельных исследовательских задач можно отдельно оценить неопределенность и применимость каждого события.

## 4. Исправление соответствия полей ISC-GEM

В официальном CSV есть два разных столбца:
- `s` (позиция 14 в CSV, индекс 13 в Python) — сохраняется как `mw_solution_code`;
- `mo_auth` (позиция 17, индекс 16) — сохраняется как `mw_source`.

Ранее импортёр ошибочно записывал `s` в поле `mw_source`. Соответствие исправлено, а тест проверяет оба поля. Для ComCat дополнительно сохраняется исходная величина в `reported_magnitude`, даже когда тип не является Mw.

## 5. Сверка с текущим ComCat по явному ISC-GEM ID

Сопоставление выполнялось только по алиасу `iscgem<eventid>` в ComCat `properties.ids`, без эвристического поиска по близким координатам и времени.

- Найдено 51 739 уникальных ISC-GEM ID-алиасов в текущем ComCat.
- 50 606 ID сопоставлены с основным ISC-GEM v13.0.
- Еще 266 ID относятся к Supplementary; 867 ID не обнаружены в двух предоставленных CSV.
- За 1976–2022 годы основной каталог содержит 58 347 событий; явная ID-связка найдена для 50 606 (86.7%). Отсутствие алиаса не означает, что события нет в ComCat.

Среди 50 606 связок у 37 819 записей ComCat тип магнитуды также Mw-совместимый (`mw/mww/mwc/mwb/mwr`). Для этой подвыборки:
- медианная абсолютная разница Mw — 0.03;
- 90-й процентиль абсолютной разницы — 0.08;
- 94.6% различий не превышают 0.10;
- медианное расстояние между эпицентрами — 9.55 км;
- медианная абсолютная разница времени происхождения — 1.1 с.

При этом в связанных ComCat-записях часто предпочтительной магнитудой является mb или Ms. Такие значения **не** конвертируются автоматически в Mw. В нормализованной таблице исходная величина остается в `reported_magnitude`, а исходный тип — в `magnitude_type`.

Покрытие явными ID-алиасами по периодам:

| Период | Main ISC-GEM | Сопоставлено | Доля |
|---|---:|---:|---:|
| 1976–1989 | 12 188 | 11 070 | 90.8% |
| 1990–1999 | 9 464 | 9 156 | 96.8% |
| 2000–2009 | 13 950 | 13 680 | 98.1% |
| 2010–2019 | 17 401 | 13 948 | 80.2% |
| 2020–2022 | 5 344 | 2 752 | 51.5% |

Снижение доли явных ID в более поздние годы не трактуется как потеря событий: это только покрытие конкретного механизма связывания идентификаторов.

## 6. Объединенная выборка

Для диагностической объединенной таблицы к 76 944 основным записям ISC-GEM добавлены 7 163 записи текущего ComCat-снимка с датой после 2022-12-31. Итого — 84 107 записей, из которых 81 213 имеют явную Mw-магнитуду по правилам импортёра. Для ComCat в добавочной части 4 269 событий имеют Mw-совместимый тип, 2 894 — другие типы.

Годовые и пространственные счетчики строятся только для Mw-eligible событий с известной глубиной 0–70 км. Это диагностика, а не формальная оценка региональной полноты Mc.

## 7. Ограничения для прогнозирования

1. ISC-GEM v13.0 опубликован в октябре 2026 года. Его нельзя использовать как набор информации, якобы доступной на исторической дате до публикации, в строгом слепом тесте.
2. ISC-GEM ориентирован на крупные события (в общем случае Mw около 5.5 и выше, с отдельными континентальными событиями до Mw 5.0); он не обеспечивает глобальную полноту по малым магнитудам для всех регионов и эпох.
3. Текущий ComCat — современный пересматриваемый снимок, а не восстановленная историческая версия каталога на каждую дату.
4. ISC-GEM v13.0 полезен как исторический контрольный и калибровочный набор, но не заменяет Global CMT выборку и исходные родительские карты, необходимые для воспроизведения GEAR1.
5. Подготовка каталога сама по себе не дает калиброванных вероятностей землетрясений. Для этого еще нужны пространственно-временная оценка полноты, определение целевых порогов и отдельная валидация.
