# Аудит родительской карты сглаженной сейсмичности GEAR1

**Дата расчета:** 2026-11-11  
**Файл:** `GL_HAZTBLT_M5_B2_2013.TMP`  
**Назначение:** входной Kagan–Jackson long-term seismicity parent, а не финальная карта GEAR1.

## Контроль целостности и геометрии

SHA-256 входного файла совпал с проверенным манифестом: `a8b6f73b8ae2a7f98868972d8b49e05055e4d1efe8f8264385ec0b07128663bf`.

В таблице ровно 6 480 000 записей: 1 800 широтных рядов × 3 600 долготных ячеек. Все координаты идут в ожидаемом порядке: долгота от −179,95° с шагом 0,1°, широта от 89,95° к −89,95° с шагом 0,1°. Все значения третьей колонки конечные и положительные.

## Метод

Интегрирование выполнено потоково, без загрузки всей карты в память. Для каждой строки вычислялась площадь сферической ячейки теми же константами и формулой, что и подпрограмма `Integrate_DP_Grid` исходника GEAR1:

- радиус Земли: 6 371 000 м;
- `PI = 3.1415927`;
- `radians_per_degree = 0.0174533`;
- шаг ячейки по долготе и широте: 0,1°.

Плотность преобразована из событий/(день·км²) в событий/(секунду·м²), после чего интегрирована по глобальной сетке и умножена на 365,25 суток в году.

Повторить проверку можно командой:

```bash
python3 research/audit_gear1_smoothed_parent.py \
  data/external/gear1/run/GL_HAZTBLT_M5_B2_2013.TMP \
  --output data/external/gear1/smoothed_parent_audit.json
```

## Интерпретация и ограничения

Полученные 176,47 событий/год — интеграл **входной карты S-parent** с порогом M>5,8, а не прогноз итогового гибрида H*. В авторском исходнике этот интеграл является исходной величиной этапа 1; далее модель экстраполирует S-parent по магнитудным порогам и объединяет его с Tectonics parent.

Этот результат не подтверждает прогностическую эффективность GEAR1 и не заменяет запуск авторского кода. Сравнивать число следует с соответствующей строкой `Integral is ... shallow EQs above threshold per year` в логе исходной программы; ожидается округление примерно до 176,47.

Машина исполнения в текущем окружении ограничена 4 GiB RAM. Поэтому полный этап гибридизации, который по исходному коду дополнительно выделяет массив H* размером около 1,6 GB при уже выделенных родительских массивах, здесь не запускался. Оригинальные Windows x64 EXE остаются предпочтительным путем для воспроизведения на подходящей машине. GNU Fortran compatibility build — диагностический/альтернативный вариант, использующий иной RNG вместо Intel MKL VSL.
