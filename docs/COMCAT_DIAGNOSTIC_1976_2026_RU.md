## 3. Главный вывод: нельзя использовать Mw-фильтр ComCat как единую историческую выборку

Распределение типов магнитуд резко меняется во времени:

- В 1976–1979 годах основная масса событий записана с типами `mb` и `ms`; Mw-типы составляют лишь малую долю.
- В 1980-х и 1990-х растет доля `mw`, `mwc`, `mwb`.
- В 2000-х и позднее структура предпочтительных типов снова меняется; в 2020-х заметно преобладает `mww`.

Следовательно, скачки годовых Mw-частот нельзя интерпретировать как изменение физической сейсмичности. Они отражают в том числе смену типов магнитуды, возможностей сетей наблюдений, алгоритмов обработки и каталожной полноты.

**Решение:** текущий ComCat-снимок годится для аудита структуры источника и как современный оперативный слой, но не как самостоятельная однородная история Mw для глобальной долгосрочной модели. Необходимо:
1. использовать ISC-GEM v13.0 как исторический каталог с унифицированными Mw и опубликованными неопределенностями;
2. сопоставить ISC-GEM и ComCat по событиям в перекрывающихся периодах и проверить остаточные систематические различия;
3. для недавнего продолжения ComCat использовать документированные преобразования магнитуд с неопределенностями, а не жестко выбрасывать все не-Mw события;
4. для ETAS и локальных краткосрочных моделей отдельно оценивать региональные пороги полноты и преобразования магнитуд.

Этот отчет не объявляет глобальный порог полноты. Даже после приведения шкал нужно оценивать полноту во времени и пространстве по регионам.

## 4. Ограничение для исторических тестов

Снимок ComCat получен 9 ноября 2026 года. Его предпочтительные магнитуды, местоположения и продукты могли быть пересмотрены после времени возникновения исторических событий. Поэтому это **современный ретроспективный снимок**, а не информация, доступная наблюдателю в 1976, 2000 или 2023 году.

Не использовать его для утверждения, что был воспроизведен исторический прогноз as-of. Для такой проверки нужны сохраненные версии каталога и продуктов, реально доступные на дату каждого выпуска.

## 5. Файлы воспроизводимого артефакта

Артефакт GitHub Actions содержит:

- `comcat_current_snapshot.geojson` — исходный снимок запроса;
- `global_catalogue_normalized.csv` — нормализованные записи, включая не-Mw типы;
- `annual_global_counts.csv` — годовые числа по магнитудным порогам;
- `spatial_counts_5deg.csv` — пространственная диагностика в ячейках 5° × 5°;
- `catalog_manifest.json` — параметры запроса, counts, хеш и ограничения;
- `catalog_audit.md` — этот сводный отчет.

Снимок ComCat и производные CSV не включаются в Git, чтобы не раздувать репозиторий. Полный ZIP артефакта доступен по странице запуска Actions выше.

## 6. Следующее действие

Для исторической основы нужен официальный **ISC-GEM v13.0 main catalogue CSV**. Скачивание выполняется вручную через форму ISC (там есть CAPTCHA): https://www.isc.ac.uk/iscgem/download.php. Исходный файл нельзя модифицировать; его хеш и метаданные будут сохранены в манифесте. Supplementary catalogue можно приложить отдельно для анализа событий с повышенной неопределенностью, но он не будет автоматически включаться в основной rate fit.

После импорта ISC-GEM:
1. сравнить его с ComCat в периодах пересечения;
2. решить правила дедупликации и магнитудной совместимости;
3. провести пространственно-временной аудит полноты;
4. перейти к воспроизведению опубликованных родительских карт GEAR1 из архива авторов.
