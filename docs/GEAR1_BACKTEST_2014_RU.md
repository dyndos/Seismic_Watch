# GEAR1: пространственный backtest 2014 года

## Назначение

Модуль `research/gear1_backtest.py` потоково читает оригинальный CSEP XML GEAR1 и сопоставляет прогноз с событиями из `global_catalogue_normalized.csv`. Он не загружает XML размером около 4 ГБ в память целиком.

Формируются три файла:
- `gear1_backtest_metrics.json` — глобальные метрики по каждому порогу Mw;
- `gear1_event_matches.csv` — прогнозная интенсивность в ячейке каждого наблюдавшегося события;
- `gear1_spatial_summary.csv` — агрегаты прогноза и наблюдений по ячейкам 5° × 5°.

## Магнитудные бины

Метаданные XML задают нижнюю границу 5.95, ширину 0.1 и открытый последний бин. 31 значение на ячейку трактуется как инкрементальные ожидаемые количества по интервалам [5.95, 6.05), [6.05, 6.15), далее с шагом 0.1 и последний [8.95, +∞). Для порога Mw ≥ X значения соответствующих бинов суммируются. Такая интерпретация согласуется с описанием GEAR1 у Bird et al. (2015), стр. 2553, DOI: https://doi.org/10.1785/0120150058.

## Отбор событий

Включаются только события с mw_eligible=true, Mw ≥ 5.95, известной глубиной внутри слоя XML (0–70 км), корректными координатами и временем внутри [2014-01-01, 2015-01-01). Неизвестная глубина не считается мелкой; не-Mw величины не пересчитываются; повторяющийся event_id приводит к ошибке.

## Временные окна

Полный 2014 год маркируется как hindcast с последней датой каталога калибровки 2013-12-29. Это не оперативный прогноз, опубликованный до начала года: issueDate XML — 2014-06-04T23:59:59Z.

Отдельно рассчитывается подвыборка событий строго позже issueDate и до 2015-01-01. Ожидаемое число событий GEAR1 для этого окна пропорционально масштабируется по доле длительности окна в исходном годовом периоде. Это подвыборка того же статического прогноза, не отдельный новый прогноз.

## Метрики

Для каждого порога Mw ≥ X выводятся ожидаемое и наблюдавшееся числа событий, отношение observed/expected и пространственный information gain в битах на событие. Последний показатель сравнивает пространственное правдоподобие GEAR1 с равномерным по сферической площади распределением, имеющим то же глобальное ожидаемое число событий. Он изолирует пространственную форму и не заменяет проверку калибровки общего числа.

Если событие оказалось в ячейке с нулевой интенсивностью, точечный log score равен минус бесконечности; JSON сохраняет null и отдельный флаг такого случая.

## Запуск (Windows PowerShell)

Выполнять из корня локального клона Seismic_Watch:

```powershell
python -m research.gear1_backtest `
  --xml "E:\Projects\Seismic_Watch\data\external\gear1\run\GEAR1.global.forecast.xml" `
  --catalog "research\outputs\global-catalogue\global_catalogue_normalized.csv" `
  --output-dir "research\outputs\gear1-backtest-2014" `
  --summary-grid-degrees 5
```

Путь к XML соответствует локальному пути из предоставленного отчета; при необходимости замени только его. После завершения пришли `gear1_backtest_metrics.json`. Сам XML и два CSV повторно загружать не нужно.

## Ограничения

1. Каталог включает современную версию ISC-GEM v13, опубликованную в 2026 году, а не сохраненный на 2014 год снимок. Это не полностью blind/as-of backtest.
2. Полное окно и post-issue окно относятся к одному календарному году и не являются независимыми испытаниями.
3. GEAR1 — статическая долгосрочная модель. Она не разделяет главные толчки и афтершоки; модуль не выполняет declustering.
4. Не моделируются пространственно-временная полнота каталога, ошибки и неопределенность гипоцентров и Mw, а также зависимость событий.
5. Area-uniform — прозрачный базовый пространственный эталон, не официальный CSEP тест и не репликация полной процедуры CSEP.
6. Один год не позволяет сделать надежный вывод о стабильном навыке модели; нужны другие независимые периоды и дополнительные baseline-модели.
