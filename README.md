# Seismic Watch

**Портфолио-проект системного / бизнес-аналитика.** Оценка вероятного места и срока
**следующего** значимого землетрясения по статистике исторических последовательностей,
типу разлома (тензор момента USGS) и границам литосферных плит — без ограничения по
расстоянию внутри плитной системы (например, цепочки вида Турция 2023 → Марокко → Афганистан →
Непал → Япония).

**Это учебный / пробный проект и не подлежит построению любых теорий, решений и предположений!**

## Ценность

Проект имеет теоретическую значимость для бизнес-планирования в принятии решений 
по рискам для своих и партнерских активов, планированию командировок и пр.

## Ключевая идея

Тип разлома (`rake`-угол тензора момента) отвечает на вопрос **как**
взаимодействуют плиты (надвиг / сброс / сдвиг), а `strike` + `dip` — **в какую
сторону** движется поддвижная плита. После крупного события нагрузка
перераспределяется вдоль тектонических структур, поэтому «следующее» событие
может произойти в другом регионе, но на той же системе плит. Инструмент проверяет
эту гипотезу статистически: для исторических аналогов триггера считается доля
случаев, когда за окном 3/6/12 месяцев следовало удалённое событие M≥6.5 на
расстоянии ≥1000 км на другом сегменте общей плитной системы.

## Возможности

| Раздел | Метод |
|---|---|
| Мониторинг | живой фид значимых событий USGS (30 дней) |
| Механизм очага | классификация по Aki & Richards (strike/dip/rake), азимут скольжения с учётом dip, схема «beachball» |
| Афтершоки | Reasenberg–Jones (1989): ожидание + вероятность P(≥1)=1−e^(−λ) |
| Межрегиональный прогноз | эмпирические частоты последовательностей по каталогу M≥6 за 20 лет |
| **Валидация** | hindcast: обучение строго до даты триггера, сверка с фактом («Турция 2023 → Марокко M6.8 через 214 дней») |
| Цепочка событий | фактические M≥6.2 за 12 мес после триггера с флагом «та же система» |
| Экспозиция | объекты компании (≤1500 км), города (≤1000 км), риск-профиль города для командировок |
| Карта | Leaflet: эпицентр, афтершоки, границы плит, стрелка движения плиты, кольца радиусов |

## Запуск

### Вариант 1 — Docker (всё в один контейнерный стек)

```bash
git clone <your-fork> && cd seismic-watch
docker compose up --build
# → http://localhost:3000
```

PostgreSQL поднимается в соседнем контейнере; таблицы и сид объектов компании
создаются автоматически при первом запросе.

### Вариант 2 — локально (Node 20+ и PostgreSQL)

```bash
npm install
cp .env.example .env            # укажите свой DATABASE_URL
npm run build && npm start      # → http://localhost:3000
# для разработки: npm run dev
```

Нужен доступ в интернет: живые данные подтягиваются из USGS. Каталог границ плит
зашит в репозиторий (`public/data/plates.geojson`).

Быстрый старт: откройте кейс **«Турция, Кахраманмараш M7.8»** — первый расчёт
занимает 5–60 с (мировой каталог M≥6 за 20 лет), далее — мгновенно из кэша БД.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| `POST` | `/api/analyze` | полный анализ: `{key: usgsId}` или `{spec: {latitude, longitude, magnitude, faultType?}}` |
| `GET` | `/api/feed` | значимые события USGS за 30 дней (кэш 10 мин) |
| `POST` | `/api/match` | сопоставление новости с каталогом: `{magnitude?, date, latitude?, longitude?}` |
| `GET` | `/api/exposure?city=…` | риск-профиль города (30 лет каталога, Poisson, кэш 24 ч) |
| `GET` | `/api/health` | проверка доступности и подключения к БД |

## Структура

```
src/
├── lib/                 # доменная логика (перенос и исправление python-прототипа)
│   ├── usgs.ts          # клиент USGS ComCat + извлечение тензора момента
│   ├── classifier.ts    # классификация разлома, азимут скольжения (с учётом dip)
│   ├── models.ts        # Reasenberg–Jones, статистика региона
│   ├── regional.ts      # межрегиональный прогноз + hindcast-валидация + цепочка
│   ├── boundaries.ts    # PB2002: индекс, ближайшая граница, плиты в радиусе
│   └── analysis.ts      # оркестратор конвейера анализа
├── db/                  # Drizzle: схема + авто-DDL, кэш анализов, объекты, логи
├── app/api/             # feed / analyze / match / exposure / health
└── components/          # дашборд, карта (Leaflet), beachball, формы
public/data/             # GeoJSON границ плит PB2002
```

## Источники данных (открытые)

- **USGS ComCat** — каталог событий и тензоры момента: `https://earthquake.usgs.gov/fdsnws/event/1/`
- **PB2002** — границы литосферных плит (Peter Bird, 2003), `fraxen/tectonicplates`

## Границы применимости

- Вероятности — **эмпирические частоты**, а не физическая модель переноса
  напряжений Кулона (для неё нужна 3D-геометрия разломов).
- Корреляция ≠ причинно-следственная связь; события иных систем помечаются.
- Не является официальным прогнозом; не заменяет решения служб ГО.
